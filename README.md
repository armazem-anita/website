# Armazém Anita

Site do [Armazém Anita](https://armazem-anita.vercel.app) — armazém e bar no Jardim Botânico (Porto Alegre).

One-page em Next.js com cardápio, agenda, galeria e CTAs locais (telefone, mapa, horários).

## Stack

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS 4

## Rodar local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npm run build
npx vercel --prod
```

Demo: https://armazem-anita.vercel.app
